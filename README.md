# Grade 7 English Adventure — with Teacher Dashboard

**English Teacher: Ms. Ebtisam Alkeebali | الأستاذة ابتسام الكيبالي**

An original 2026–2027 Grade 7 English practice website aligned with the uploaded Grade 7 EOT1 specification. Read-only official format: 60 objective marks and separately teacher-assessed 40 writing marks. The site does **not** supply official writing rubric criteria or an official time limit, because the source specification does not.

## Open or publish

- Open `index.html` to use the standard website. The optional standalone HTML works offline without the other files.
- GitHub Pages: create a public GitHub repository, upload `index.html`, `style.css`, `data.js`, `app.js`, plus the `assets/` folder, then use **Settings → Pages → Deploy from branch → main → /(root)**. Copy the live public URL GitHub shows.
- **Never upload student report JSON or teacher-exported CSV files to a public GitHub repository.** Student reports are private classroom records.

## How students share progress

1. Each student completes activities on her own browser, then opens **My Progress**.
2. She selects class **7/1** or **7/2** and enters a code provided by her teacher (3–20 letters/numbers/dashes/underscores). Her nickname is optional.
3. To share original mock-exam writing text for teacher feedback, she checks **Include my submitted mock-exam writing answers**. Otherwise only word counts are included.
4. She clicks **Download My Progress Report**, creating a `.json` file.
5. She sends this file privately to the teacher via a school-approved platform, not a public link.

## How the teacher views progress

1. On the teacher's own trusted device, open **Teacher Dashboard** in the site navigation.
2. Use the **Select JSON reports** field to pick multiple received student files, then click **Import Selected Reports**.
3. View 7/1 or 7/2 separately, search by student code, inspect practice scores, objective mock scores and writing (if included).
4. Optionally enter manually awarded **writing marks out of 40** (stored *only on this teacher browser*). The dashboard can calculate objective + writing out of 100, without claiming to use an official rubric.
5. Export filtered **CSV for Excel**, or print the dashboard. Imports for a matching class + code update the existing record instead of creating duplicates; older exports do not replace newer files.
6. Use **Clear All Imported Reports** to remove the local records from this teacher browser.

## Important limitations and privacy

- **This is not automatic or real-time tracking.** GitHub Pages is a static host. The teacher can see only report files deliberately imported on her device; she cannot see scores just because students visited the website.
- There is no login, authenticated staff area, central classroom database or online syncing. The Teacher Dashboard is publicly reachable but is empty unless a browser locally imports a report; it must **not** be treated as a protected online record system.
- Browser local storage is not an appropriate protected database for permanent student records. Use a trusted school device, use pseudonymous student codes, transfer files through school-approved channels, and keep only the minimum data necessary. Export CSV and store it according to school policy.
- For automatic centralized teacher-only progress reporting, a school-approved backend with authentication, database and permissions is needed; do not enter confidential student information until it is approved.
- The student browser stores a draft of submitted mock writing to enable optional export; writing is **not automatically scored**.
- Students sharing the same computer/browser profile would share that local browser's saved progress. Use individual browser profiles/devices.

## Exam structure

| Part | Official pattern | Marks |
|---|---|---|
| Vocabulary | 5 standalone 3-option gap-fill MCQs | 10 |
| Grammar | 120±10%-word descriptive text with five 3-option gaps | 10 |
| Reading 3A | A2 narrative, 170–200±10% words, 8 MCQs | 24 |
| Reading 3B | B1.1 expository Islamic art patterns, 170–200±10% words, 8 MCQs | 16 |
| Writing | Four labelled pictures, at least 100 words, sequencing expressions | 40 (teacher) |

Every teacher CSV export includes the name Ms. Ebtisam Alkeebali.
