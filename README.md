# Grade 7 English Adventure — Private Browser-Only Edition

**Teacher:** Ms. Ebtisam Alkeebali | الأستاذة ابتسام الكيبالي

## How students use the website

1. Open https://ebtisamalkibaly-droid.github.io/grade7-english-adventure/
2. Enter the full name and choose class **7/1** or **7/2**.
3. Choose **Start My Adventure**, then practise vocabulary, grammar, reading, writing and mock exams.
4. All progress is saved **only in that browser**. There are no student passwords, student accounts, Firebase connection, or automatic upload.
5. To share scores privately, go to **My Progress → Download My Progress Report**, then send the downloaded JSON file through a teacher-approved private channel. Written exam text is included only if requested through the opt-in checkbox.

## Teacher Dashboard

- Open **Teacher Dashboard** on a trusted teacher-only browser.
- Choose student JSON reports and select **Import Selected Reports**.
- Filter by 7/1 or 7/2, search by name, inspect activities, and export CSV for Excel.
- Teacher-entered writing marks /40 are kept only in the teacher's browser.
- **The dashboard is not access-controlled; anyone can open the empty dashboard, but imported reports are only present on the browser where they were imported.** Do not import personal student data on a shared computer.

## Privacy notes

- GitHub Pages provides the static website and cannot automatically collect scores from student devices by itself.
- There are **no automatic external tracking or data sync services** loaded by the published website.
- Student-entered names are not identity-verified and students sharing one browser profile may overwrite each other's local progress.
- Data in browser storage may be lost when storage is cleared.
- **No Firebase setup is necessary for this edition.** Old Firebase-related files may remain in the repository but are not loaded by index.html.
- Avoid putting student names, progress JSON, teacher CSV exports, or passwords in a public repository.

## Exam alignment

Grade 7 EOT1 2026–2027 practice: 60 objective marks (Vocabulary 10, Grammar 10, Reading 3A 24, Reading 3B 16) and separately teacher-scored writing /40. Practice writing uses four labelled pictures and at least 100 words. The official time limit and detailed writing rubric were not available in the supplied specification; this site does not invent them.
